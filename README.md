# C++ Number Utility Program

A console-based menu-driven utility written in C++ providing several standard number-theory operations.

## Features
- **Prime Number Check**: Validates whether a number is prime using trial division up to $\sqrt{n}$.
- **Palindrome Check**: Verifies if an integer reads the same forwards and backwards.
- **Factorial**: Computes factorial for positive numbers.
- **Fibonacci Series**: Generates the first $n$ numbers in the Fibonacci sequence.
- **Reverse Number**: Reverses the digits of a given integer.
- **GCD & LCM**: Computes Greatest Common Divisor (Euclidean algorithm) and Least Common Multiple.

## How to Compile & Run

```bash
g++ -o math_utils main.cpp
./math_utils
